Backend Google Apps Script otomatis

Aplikasi terhubung langsung ke Google Spreadsheet melalui backend Apps Script yang melayani aplikasi ini. URL deployment /exec ditetapkan pada konfigurasi deployment/backend, bukan diinput atau direkam oleh pengguna.

Status koneksi diperiksa otomatis saat aplikasi dibuka.

⚙️ Konfigurasi Backend

1Pengelola menetapkan Spreadsheet tujuan pada project Google Apps Script yang terikat pada Spreadsheet tersebut.
2Backend menyiapkan sheet TRANTIB, header, dan folder FOTO_TRANTIB secara otomatis saat diperlukan.
3Deploy Web App menggunakan URL /exec. Pengguna cukup membuka URL aplikasi; tidak perlu memasukkan URL, menekan Hubungkan, atau menyimpan pengaturan koneksi.
Sinkronisasi data berlangsung otomatis melalui backend. Foto disimpan di Google Drive dan tautannya dicatat pada Spreadsheet.
